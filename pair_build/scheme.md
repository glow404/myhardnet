数据集构建阶段

1.对于局部点/锚定点，选择SIFT算法提取关键点当作锚定点

2.**同一手指图像之间建立对应关系**

通过sift对应的匹配算法，通过粗匹配+细匹配，筛选出稳定的对应点。

3.目标1：使用hardnet网络训练出来的hardnet描述子替换sift描述子去进行类sift的指纹匹配识别流程。

4.目标2：要求使用hardnet描述子得到内点数比单纯使用sift更高，正样本描述子距离/负样本描述子距离的值比sift的更低。

5.对于第4点，要求后续做出相对应的测试和对比模块，并有可视化输出展示。

5.1这里负样本选择同一手指不同物理点

6.为了达到目标2，数据集的构建使用“几何引导正样本扩展”：

先用严格 SIFT 匹配 + RANSAC 几何验证，得到仿射矩阵T，

对图像 A 中每个 SIFT keypoint（关键点）kp_a：
   \- 使用 T 将 kp_a 坐标投影到图像 B。
   \- 在图像 B 的 keypoints（关键点）中搜索投影点附近的候选 kp_b。

6.1候选点筛选问题

投影距离小于阈值，例如 3-8 px，视分辨率而定
SIFT keypoint orientation 差异小于阈值
scale ratio 合理，例如 0.7-1.4
response / contrast 不太低
patch 不靠近边界
前景 mask 占比足够
可选：局部 patch NCC / SSIM 不能太差
可选：mutual geometric nearest

6.2 多个候选点问题

按综合分排序：

score = 坐标残差 + 方向差 + scale 差 + patch 相似度惩罚





（后续可以采用更强的几何模型，比如局部仿射，TPS / thin plate spline 非刚性配准）

7.几何引导正样本扩展时使用sift提取关键点时的参数可以略微宽松一点。（第一阶段可以忽略）



8.关于伪负样本问题

法1：把所有属于同一物理对应点的设置标签归类，每次只从一个类里取两个

法2：训练网络时，一个人的一个手指，只取两张图中的patch作为训练数据。每个batch有多个手指，每个手指只提供两张图去提供patch块作为训练数据。这样可以尽可能避免伪负样本对问题。
